# Academia Miriam Sandoval — Landing page

Página de captación de alumnas para el curso de Alta Costura.
Medellín, barrio Calasanz.

## Cómo verla

Abre `index.html` con doble clic. No necesita servidor, ni instalar nada,
ni conexión a internet (salvo para el mapa y las tipografías).

## Qué hay dentro

| Archivo | Qué es |
|---|---|
| `index.html` | La página completa: estructura, estilos y comportamiento en un solo archivo |
| `img/` | Las 14 fotos optimizadas que usa la página (2 MB en total) |
| `img/LEEME-imagenes.md` | Qué foto va en cada nombre de archivo |

## Objetivo de la página

Que la visitante escriba por WhatsApp para **agendar una visita presencial al taller**.
No hay carrito ni pago en línea: la inscripción se cierra en persona.

Hay 11 botones repartidos por la página y todos llevan al mismo WhatsApp
(313 257 5989), cada uno con un mensaje distinto ya escrito. Así, al leer el
chat se sabe desde qué sección escribió cada persona.
